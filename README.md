# 🇧🇯 GSM Benin Checker

**GSM Benin Checker** est une application web légère et responsive conçue pour identifier instantanément l'opérateur mobile d'un numéro béninois suite au passage au plan national de numérotation à **10 chiffres**.

## 🚀 Fonctionnalités

- **Identification instantanée** : Détecte si un numéro appartient à **Moov Africa**, **MTN Benin** ou **Celtis** dès la saisie du préfixe.
- **Interface Responsive** : Optimisée pour une utilisation fluide sur mobile (iPhone/Android) et desktop.
- **Conformité ARCEP** : Basé sur les directives officielles de l'Autorité de Régulation du Bénin.
- **Confidentialité** : Aucune donnée n'est stockée, l'analyse se fait localement en JavaScript.

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique.
- **CSS3** : Design moderne avec Flexbox/Grid et gestion de la responsivité (Media Queries).
- **JavaScript (Vanilla)** : Logique de détection des préfixes et interactions dynamiques .

## 📱 Aperçu

Le site s'adapte parfaitement aux écrans mobiles, avec un menu de navigation escamotable pour laisser place à la saisie.

## 📖 Comment ça marche ?

1. Saisissez les premiers chiffres du numéro dans le champ dédié.
2. L'icône de l'opérateur s'affiche automatiquement.
